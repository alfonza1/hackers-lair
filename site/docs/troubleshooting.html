Guide 05 // troubleshooting

Read the signal before changing the machine.

Start with Doctor. Its report checks tools, data-directory access, config validation, folders, and local port state, and can be copied with usernames and absolute paths redacted.

lair doctor

Port 4949 is in use

The control service tries 4949, then 4950 through 4959. Port drift is expected and safe: the desktop host and CLI read the actual bound port, nonce, PID, and token from the runtime identity file and verify /api/identity before connecting.

If all ten ports are occupied, open the Port Signals view in an existing Hacker's Lair instance or identify the owners with:

Windows

Get-NetTCPConnection -State Listen | Where-Object { $_.LocalPort -ge 4949 -and $_.LocalPort -le 4959 } | Select-Object LocalPort,OwningProcess

Linux

ss -ltnp | grep -E ':(4949|495[0-9])\b'

Do not kill an unknown process. Confirm its command line first.

A project starts but is not detected

  1. Confirm the configured port is actually listening, not only printed in a startup message.
  2. Make match more distinctive—prefer the absolute project folder over a generic executable name.
  3. For Docker, declare every required published listener in ports and add a stopCommand.
  4. For workers with no listener, set track to process.
  5. Open the component log and inspect the exact start command, working directory, and error output.

Configured ports appear as muted Ports chips. They become bright Detected chips only while live, so a muted chip is not itself an error.

A config parse error banner appears

The app keeps the last known-good config in memory and shows the file and parse position. Open the listed file, fix the JSON syntax, and refresh. Doctor and the in-app schema summary report validation errors separately from JSON syntax errors.

Restore the previous known-good write from Settings or the CLI:

lair backups
lair restore <backup-file-name>

The ten newest versions are retained in the data directory's backups folder.

A firewall prompt appears

The Hacker's Lair control API binds to 127.0.0.1, validates the Host header, and does not need inbound network access. A firewall dialog may belong to a managed dev server configured to listen on all interfaces. Read the executable and network scope in the prompt; do not approve access merely because Hacker's Lair launched the command.

PROJECT_MANAGER_DATA_DIR changes both paths for development and diagnostic runs. The directory also holds configs, backups, activity history, preferences, and the rotating api-token identity file.

The desktop opens but the service does not

Quit the desktop app completely, including its tray icon, then relaunch it. The Electron host owns the server lifecycle and refuses to load a process that only happens to answer on a candidate port. If the issue continues, copy the Doctor report and include the release version, operating system, installation channel, and visible error.

Copy a safe support report

Select Copy report in Doctor or run:

lair doctor

Review the result before posting. The formatter redacts usernames and absolute machine paths, but project names and tool versions remain because they are useful diagnostic signals.
