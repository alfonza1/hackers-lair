Guide 07 // uninstall

Remove the app. Choose what happens to your data.

Quit Hacker's Lair from the tray before removal. Uninstalling the app does not delete project source folders or terminate unrelated dev processes.

Windows

Winget status

Package ID hackerslair.desktop is pending community approval, so there is no active Winget installation to remove yet.

PowerShell channel

irm https://hackerslairhq.github.io/desktop/uninstall.ps1 | iex

The script verifies and stops only the running Hacker's Lair executable whose path belongs to the per-user installation. It then asks whether to retain or delete %APPDATA%\HackersLair. For a non-interactive local script run, use -KeepData or -DeleteData.

Scoop

scoop uninstall hackerslair

Scoop removes the package and shim. Remove the bucket only if you no longer use it:

scoop bucket rm hackerslair

Optional Windows user-data cleanup

Remove-Item -LiteralPath (Join-Path $env:APPDATA 'HackersLair') -Recurse -Force
Permanent action: the user-data directory contains project config, preferences, logs, and backups. Inspect or export it before removal.

Linux

Debian / Ubuntu

sudo apt remove hackers-lair

Fedora / RHEL

sudo rpm -e hackers-lair

Distro-neutral tarball

rm -rf -- "$HOME/.local/opt/hackers-lair"

If you created a desktop entry manually, remove that specific file from ~/.local/share/applications.

Managed CLI companion

if grep -Fq "# Hacker's Lair managed CLI" "$HOME/.local/bin/lair" 2>/dev/null; then
  rm -f -- "$HOME/.local/bin/lair"
fi

The ownership-marker check preserves an unrelated command that happens to use the same lair name.

Optional Linux user-data cleanup

rm -rf -- "${XDG_CONFIG_HOME:-$HOME/.config}/HackersLair"

That removal is permanent. Keep the directory when you expect to reinstall or want to preserve config backups.

Verify the control service stopped

After the desktop host exits, its managed private server should also exit. The following commands should show no Hacker's Lair listener:

Windows

Get-NetTCPConnection -State Listen | Where-Object { $_.LocalPort -ge 4949 -and $_.LocalPort -le 4959 }

Linux

ss -ltnp | grep -E ':(4949|495[0-9])\b' || true
