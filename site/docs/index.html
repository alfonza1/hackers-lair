Guide 01 // installation

Install from a terminal.

Hacker's Lair ships self-contained desktop packages. End users do not install Node.js, clone the repository, or run npm.

Windows

Winget status

Package ID hackerslair.desktop is prepared but is not available in the community source yet. No Winget command is published here until approval is complete. Use the verified PowerShell or Scoop channel today.

Checksum-verifying PowerShell channel

This channel works directly from GitHub Releases. The script resolves the latest release, downloads the portable ZIP and checksums.txt, verifies SHA256, and only then unblocks and extracts it to %LOCALAPPDATA%\Programs\HackersLair.

irm https://hackerslairhq.github.io/desktop/install.ps1 | iex

Run it in a regular PowerShell window; administrator privileges are not needed. If the terminal is elevated, installation still completes, but automatic launch is skipped so the tray app never inherits administrator privileges.

Re-running the command updates the installation in place. It creates a Start menu shortcut but leaves launch-at-login off; that preference is controlled inside the desktop app.

Scoop

scoop bucket add hackerslair https://github.com/hackerslairhq/scoop
scoop install hackerslair

The bucket manifest consumes the same portable ZIP and release checksum as the PowerShell channel.

Linux

Debian / Ubuntu

curl -LO https://github.com/hackerslairhq/desktop/releases/latest/download/hackers-lair_amd64.deb &&
curl -LO https://github.com/hackerslairhq/desktop/releases/latest/download/checksums.txt &&
grep '  hackers-lair_amd64.deb$' checksums.txt | sha256sum -c - &&
sudo apt install ./hackers-lair_amd64.deb

Fedora / RHEL

curl -LO https://github.com/hackerslairhq/desktop/releases/latest/download/hackers-lair_x86_64.rpm &&
curl -LO https://github.com/hackerslairhq/desktop/releases/latest/download/checksums.txt &&
grep '  hackers-lair_x86_64.rpm$' checksums.txt | sha256sum -c - &&
sudo rpm -i ./hackers-lair_x86_64.rpm

Distro-neutral tarball

curl -LO https://github.com/hackerslairhq/desktop/releases/latest/download/hackers-lair-linux-x64.tar.gz &&
curl -LO https://github.com/hackerslairhq/desktop/releases/latest/download/checksums.txt &&
grep '  hackers-lair-linux-x64.tar.gz$' checksums.txt | sha256sum -c - &&
mkdir -p "$HOME/.local/opt/hackers-lair" &&
tar -xzf hackers-lair-linux-x64.tar.gz -C "$HOME/.local/opt/hackers-lair" --strip-components=1 &&
"$HOME/.local/opt/hackers-lair/HackersLair"

The desktop app uses $XDG_CONFIG_HOME/HackersLair when that variable is set, otherwise ~/.config/HackersLair. The Windows-only AutoIt Scripts view is hidden automatically.

Verify SHA256 manually

Every release includes checksums.txt. Download the artifact and checksum file from the same tag, then compare locally.

Windows PowerShell

$Expected = (Select-String -Path .\checksums.txt -Pattern "hackers-lair-win32-x64.zip").Line.Split()[0]
$Actual = (Get-FileHash .\hackers-lair-win32-x64.zip -Algorithm SHA256).Hash.ToLowerInvariant()
if ($Actual -ne $Expected.ToLowerInvariant()) { throw "SHA256 mismatch" }

Linux

sha256sum --ignore-missing -c checksums.txt

Verify build provenance

GitHub Actions also creates a signed build-provenance attestation for every release artifact. With the GitHub CLI installed, verify that a downloaded file came from this repository's release workflow:

gh attestation verify <file> -R hackerslairhq/desktop

Use the attestation and checksums.txt together: the checksum detects changed bytes, while the attestation ties those bytes to an authenticated GitHub Actions build for this repository.

Signing status: provenance attestation is not Windows publisher code signing and does not remove SmartScreen reputation prompts. Release packages are checksum-published but not currently code-signed. Hacker's Lair never instructs you to disable SmartScreen or other security controls.

Runtime requirements

  • Windows: 64-bit Windows 10 or 11.
  • Linux: x86_64 desktop Linux with ss or lsof and ps.
  • Projects: only the tools your own start commands require, such as Git, Docker, Java, Python, or npm.
  • Hacker's Lair itself: no separately installed Node.js or npm.
