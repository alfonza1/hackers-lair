Guide 03 // configuration

Project configuration reference.

The wizard and project editor are the normal interface. This reference exists for automation and power users; the bundled JSON Schema powers editor autocomplete and server validation from the same source.

Location and hot reload

PlatformDefault file
Windows%APPDATA%\HackersLair\projects.json
Linux$XDG_CONFIG_HOME/HackersLair/projects.json, or ~/.config/HackersLair/projects.json

PROJECT_MANAGER_DATA_DIR overrides the entire data directory. PROJECTS_FILE overrides only the project file. The app copies projects.schema.json beside the config and reads changes on refresh without a restart.

{
  "configVersion": 1,
  "$schema": "./projects.schema.json",
  "projects": []
}

configVersion is managed by the app. Ordered migrations create a backup before changing older files; newer versions are left intact so an older app can ignore fields it does not recognize.

Project fields

FieldRequiredMeaning
nameYesUnique display name used by the UI and lair CLI.
typeNoShort badge such as Vite, Next.js, Docker Compose, or FastAPI.
componentsYesOne or more launch/detection units controlled as a target.

Component fields

FieldMeaning
nameUnique component label inside its project.
roleDisplay role such as frontend, backend, worker, or fullstack.
cwdExisting absolute working directory for launch, stop, Git, and open-in actions.
commandExact shell command used to launch the component.
stopCommandOptional graceful command run in cwd before process cleanup; timeout is 60 seconds.
matchDistinctive command-line substring used to detect and stop the intended process. An absolute project path is a strong default.
portLegacy single readiness/display port.
portsAuthoritative listener set. Every declared port must be live for the component to be ready.
uiPortsConfigured ports classified as user interfaces.
backendPortsConfigured ports classified as APIs or backend services.
detectByPortRequire configured port evidence for legacy single-port entries.
trackSet to "process" for a headless process that never opens a listener.
autoRestartOpt into capped exponential-backoff restart after an unexpected exit.
maxRestartsRetry cap from 1 through 10; default is 3.
zombieAfterHoursPer-component idle warning threshold from 1 through 720 hours.

Ports must be integers from 1 through 65535 and unique across configured projects. The in-app editor enforces existing absolute folders and non-empty commands for launchable components.

Copyable examples

npm / Vite

{
  "name": "signal-ui",
  "type": "Vite",
  "components": [{
    "name": "frontend",
    "role": "frontend",
    "cwd": "C:\\Dev\\signal-ui",
    "command": "npm.cmd run dev -- --port 5173",
    "match": "C:\\Dev\\signal-ui",
    "port": 5173
  }]
}

Next.js

{
  "name": "docs-console",
  "type": "Next.js",
  "components": [{
    "name": "web",
    "role": "fullstack",
    "cwd": "C:\\Dev\\docs-console",
    "command": "npm.cmd run dev -- --port 3000",
    "match": "C:\\Dev\\docs-console",
    "port": 3000,
    "autoRestart": true,
    "maxRestarts": 3
  }]
}

Docker Compose

{
  "name": "local-stack",
  "type": "Docker Compose",
  "components": [{
    "name": "stack",
    "role": "fullstack",
    "cwd": "C:\\Dev\\local-stack",
    "command": "docker compose -p local-stack up --build",
    "stopCommand": "docker compose -p local-stack down",
    "match": "-p local-stack up",
    "ports": [5174, 4100],
    "uiPorts": [5174],
    "backendPorts": [4100]
  }]
}

Maven / Gradle

{
  "name": "catalog-api",
  "type": "Spring Boot",
  "components": [{
    "name": "server",
    "role": "backend",
    "cwd": "C:\\Dev\\catalog-api",
    "command": "mvnw.cmd spring-boot:run",
    "match": "C:\\Dev\\catalog-api",
    "port": 8080
  }]
}

For a Gradle wrapper, replace the command with gradlew.bat bootRun on Windows or ./gradlew bootRun on Linux.

Python / FastAPI

{
  "name": "events-api",

  "components": [{
    "name": "api",
    "role": "backend",
    "cwd": "C:\\Dev\\events-api",
    "command": "python -m uvicorn main:app --reload --port 8000",
    "match": "C:\\Dev\\events-api",
    "port": 8000
  }]
}

Headless process

{
  "name": "queue-worker",
  "type": "Python worker",
  "components": [{
    "name": "worker",
    "role": "worker",
    "cwd": "C:\\Dev\\queue-worker",
    "command": "python worker.py",
    "match": "C:\\Dev\\queue-worker",
    "track": "process",
    "autoRestart": true,
    "maxRestarts": 5,
    "zombieAfterHours": 12
  }]
}
Linux commands: use Linux absolute paths and native wrapper names—for example /home/dev/signal-ui, npm run dev, ./mvnw, and python3.

See how command-line and listener evidence combine before choosing a tracking mode.
